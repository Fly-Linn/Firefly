 　　今天学到了很多东西，虽然最开始都是跟着b站一步一步学习的，不过后来有了很多自己的思考。从中学习到了很多东西。  
 　　比如最开始的时候powershell没有用管理员权限打开，我是用cmd下载的依赖，然后后来发现可以使用命令使powershell打开管理员权限。  
 　　其次就是github作为一个境外的网站，在成功进入这个网站也花费了一定时间，最后还是用steam++打开的。  
 　　然后就是文章的编辑需要用.md的格式，首行缩进的话需要用两个全角空格，然后换段的话需要在段落末尾加上两个空格。
 　　部分截面优化，因为本来就会ps，所以一些图片，自己就能来做。  
 　　同时学习Visual Studio Code用来编辑网页，以及使用git将代码更新到github中。  
 　　对于个人博客的创建所需要的域名以及创建部署所需要的知识也学习到了很多。我刚开始是跟着博主用的cf平台，不过由于是国外的平台访问起来并不方便，晚上的时候改用国内的腾讯云，这一次的部署是全靠自己完成的，然后购买域名需要个人信息认证，不过这个审核1小时就通过了，明天就可以尝试购买域名了。  
  　　最后，由于是第一天学习，所以制作的并不完善，以后还要多加学习，才能将个人博客制作的更加精良美观。  
  　　以下是学习过程中使用到的网站。  
- [Firefly Docs官网](https://docs-firefly.cuteleaf.cn/zh/)
- [b站教程](https://www.bilibili.com/video/BV1Hk9fBTE6H/?share_source=copy_web&vd_source=2307b7cbf7a28ca25ec602d77d272646)
- [腾讯云部署后台](https://console.cloud.tencent.com/edgeone/makers/project/makers-tamqhs7ocq8hc/index)  
 　　再写以上链接的时候学习到利用[标题](网址)，这样的话就能够创建连接文本，避免了格式问题。  
 　　最后再次使用  
　　　　　　　　git add .  
　　　　　　　　git commit -m "本次修改说明"  
　　　　　　　　git push  
 　　将本次更新内容同步到GitHub上。
